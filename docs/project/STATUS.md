## Personal web home

`/home` in the dashboard SPA (`web/src/personal/`; `/` redirects there) is a full-screen personal surface. At the top center, an agent badge shows the onboarding `AGENT_NAME.txt` with a generated avatar that blinks when idle and animates while a turn runs; tapping it returns to the Home thread. The account menu's Settings opens a panel (popover on desktop, bottom sheet on phones) where the person picks the avatar color: automatic (from the name), six swatches, or any custom color. That choice is saved per profile in `personal_home.json` via `PUT /api/personal/preferences` and returned by `GET /api/personal/identity`. The sky follows the local clock: morning 5–11 (sunrise blue/rose/gold), day 11–17, evening 17–21 (deep blue to sea green), night. Evening and night lift the glass opacity. Dev builds accept `?sky=` to preview a phase. Chat uses `/api/ws` JSON-RPC against the Home thread; approval/clarify render as cards.

The board is stored per profile on the server (`personal_board.json` via `/api/personal/board*`) and is re-read on focus, every 30s and after each chat turn; a board an older home kept in the browser is imported once. The person adds, configures, reorders and removes tiles: Shortcuts, Calendar, Scheduled, Recent chats, Note, World clock. The agent can add cards with the `home_cards` tool, but only from a fixed catalog the home renders. Live cards use what the profile has: calendar is refused unless Google Calendar is connected; scheduled, recent and clock always work. Content cards (list, stats, text) hold data the agent fetched, with a required source and reason; list items can link out (http/https), ask the agent, or be ticked off by the person. Each agent card shows "Added by {agent} · From {source} · Updated …". The agent can update or remove only its own cards (at most 6). A card the person removes is remembered and not re-added unless they ask. Calendar signs in through Hermes's Google Workspace OAuth, the same client file, scopes, pending-session file and `google_token.json` as the google-workspace skill, so a grant made in chat lights the tile up and vice versa. A token without a calendar scope asks to sign in again; signing out from the tile revokes and deletes the shared token after an inline confirmation. Loopback origins redirect back to `/home`; others use the paste-the-redirect flow. Below 1024px, tiles open in a bottom sheet.
