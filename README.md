# Proactive Agent

A personal agent harness focused on polished interactions, accessible capabilities, useful proactivity, and excellent context continuity.

## Start working

- [AGENTS.md](AGENTS.md): agent instructions and project authority.
- [Local setup](docs/project/DEVELOPMENT.md): isolated development and validation.
- [Vision](docs/project/VISION.md) and [roadmap](docs/project/ROADMAP.md): what to build and the first tasks.
- [Architecture](docs/project/ARCHITECTURE.md) and [engineering guide](docs/project/ENGINEERING.md): where to make changes and contracts to preserve.
- [Status](docs/project/STATUS.md) and [decisions](docs/project/DECISIONS.md): verified progress and durable choices.
- [Contributing](CONTRIBUTING.md): development and review workflow.

The runtime foundation is present. Project-specific context, proactive, and UI improvements are planned in the roadmap; they are not yet shipped. Existing commands and package names retain `hermes` for compatibility.
